# J.Crew Performance Diagnosis

## Website

https://www.jcrew.com/in/

## Issues Found

1. Large hero image increases loading time.
2. Heavy JavaScript blocks rendering.
3. Unoptimized images.
4. Render-blocking CSS.
5. Multiple third-party scripts.

## Priority Fixes

| Fix | Impact | Effort |
|------|--------|--------|
| Optimize Hero Image | High | Low |
| Lazy Loading | High | Low |
| Reduce JavaScript | High | Medium |
| Compress CSS | Medium | Low |
| Preload Fonts | Medium | Low |

## Section Chosen

Hero Banner

Reason:
The hero section is the first content users see and has the biggest impact on loading speed and user experience.
